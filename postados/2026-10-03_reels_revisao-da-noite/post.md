## Legenda

Os estoicos tinham um ritual simples para a noite: revisar o próprio dia. O que fiz de bom? Onde errei? O que deixei de fazer?

Não é para se culpar. É para enxergar com clareza e ajustar a rota enquanto o erro ainda é pequeno.

A pergunta do vídeo é uma versão prática desse hábito. Às vezes a resposta é grande, como um projeto adiantado. Às vezes é pequena: uma conversa paciente, uma conta paga, uma hora de sono a mais.

Hoje à noite, responda com sinceridade: o que o seu eu de amanhã vai agradecer?

Arte: Vincent van Gogh — “A Noite Estrelada” (domínio público)
